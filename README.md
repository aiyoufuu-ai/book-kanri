# 📚 本棚かんり

スマホのカメラで本のバーコード（ISBN）を読み取って、家にある本を一覧で管理できる Web アプリです。
インストール不要で、ブラウザだけで動きます（ホーム画面に追加するとアプリのように使えます）。

## できること

- **バーコードで登録**：本の裏の `978` / `979` で始まるバーコードを読むと、タイトル・著者・出版社・表紙を自動で取得して登録します。続けて何冊でも読み取れます
  - 下段の `192...` のバーコード（価格コード）は自動で無視します
- **「持ってる？」チェック**：本屋で読み取ると、すでに持っている本かどうかと置き場所を表示します（登録はしません）
- **ISBN 手入力**：バーコードが読めない本用（10桁・13桁どちらも可）
- **一覧・検索・並び替え**：タイトル・著者・ISBN・メモで検索、置き場所で絞り込み
- **編集**：置き場所・状態（未読／読書中／読了／貸出中）・メモ。置き場所は直前に登録した本のものを引き継ぐので、棚ごとにまとめて登録すると楽です
- **バックアップ**：JSON 書き出し／読み込み、CSV 書き出し（Excel 対応）

書誌情報は [openBD](https://openbd.jp/)（国内書籍）→ 見つからなければ Google Books の順に検索します。

## 使い始め方

カメラを使うため **https での公開** が必要です。GitHub Pages で公開する手順：

1. このブランチを `main` にマージする
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. `main` へ push されると `.github/workflows/pages.yml` が自動でデプロイします
4. `https://<ユーザー名>.github.io/book-kanri/` をスマホで開き、共有メニューから「ホーム画面に追加」

> 注意：GitHub Pages は無料プランだと公開リポジトリでのみ使えます。

### ローカルで試す

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く（localhost ならカメラも使えます）
```

## データの保存場所

本のデータは**その端末のブラウザ内（localStorage）**に保存され、サーバーには送られません。
そのため別の端末とは共有されません。機種変更やブラウザのデータ削除の前には、メニュー（⋯）から JSON でバックアップしてください。

## 構成

ビルド不要の素の HTML / CSS / JavaScript です。

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `lib/zxing-browser.min.js` | バーコード読み取り（[@zxing/browser](https://github.com/zxing-js/browser) 0.2.1, MIT）。ネイティブの `BarcodeDetector` がないブラウザ（iPhone など）で使用 |
| `sw.js` / `manifest.webmanifest` / `icon.svg` | ホーム画面追加・オフライン表示用 |
