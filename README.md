# 📚 本棚かんり

スマホのカメラで本のバーコード（ISBN）を読み取って、家にある本を一覧で管理できる Web アプリです。
インストール不要で、ブラウザだけで動きます（ホーム画面に追加するとアプリのように使えます）。

## できること

- **バーコードで登録**：本の裏の `978` / `979` で始まるバーコードを読むと、タイトル・著者・出版社・表紙を自動で取得して登録します。続けて何冊でも読み取れます
  - 下段の `192...` のバーコード（価格コード）は自動で無視します
- **「持ってる？」チェック**：本屋で読み取ると、すでに持っている本かどうかと置き場所を表示します（登録はしません）
- **ISBN 手入力**：バーコードが読めない本用（10桁・13桁どちらも可）
- **一覧・検索・並び替え**：タイトル・著者・ISBN・メモで検索、置き場所で絞り込み
- **編集**：置き場所・状態（未読／読書中／読了／貸出中）・メモ。置き場所は直前に登録した本のものを引き継ぐので、棚ごとにまとめて登録すると楽です
- **Google スプレッドシート連携（任意）**：一覧をスプレッドシートに保存し、家族の複数の端末で共有。スプレッドシートを直接編集してもアプリに反映されます
- **バックアップ**：JSON 書き出し／読み込み、CSV 書き出し（Excel 対応）

書誌情報は [openBD](https://openbd.jp/)（国内書籍）→ 見つからなければ Google Books の順に検索します。

## 使い始め方

カメラを使うため **https での公開** が必要です。GitHub Pages で公開する手順：

1. このブランチを `main` にマージする
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. `main` へ push されると `.github/workflows/pages.yml` が自動でデプロイします
4. `https://<ユーザー名>.github.io/book-kanri/` をスマホで開き、共有メニューから「ホーム画面に追加」

> 注意：GitHub Pages は無料プランだと公開リポジトリでのみ使えます。

### ローカルで試す

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く（localhost ならカメラも使えます）
```

## データの保存場所

連携しない場合、本のデータは**その端末のブラウザ内（localStorage）**だけに保存され、サーバーには送られません。
機種変更やブラウザのデータ削除の前には、メニュー（⋯）から JSON でバックアップしてください。

## スプレッドシート連携

Google スプレッドシートを保存先にすると、複数の端末で同じ本棚を使えます。
サーバーの用意は不要で、Google Apps Script を使います。

### 設定手順

1. 新しい Google スプレッドシートを作る
2. メニューの **拡張機能 → Apps Script** を開き、最初からあるコードを消して [`gas/Code.gs`](gas/Code.gs) の中身を貼り付ける
3. 10行目の `TOKEN` を、自分だけの合言葉（推測されにくい長めの文字列）に書き換えて保存
4. 右上の **デプロイ → 新しいデプロイ** → 種類の選択（⚙）で **ウェブアプリ** を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」を押し、Google アカウントのアクセスを承認する（「このアプリは Google で確認されていません」と出たら「詳細 → 安全ではないページに移動」）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー
7. アプリのメニュー（⋯）→「Googleスプレッドシート連携」に URL と合言葉を入れて「保存」

最初に連携したとき、その端末に登録済みの本はスプレッドシートへ送られます。家族の端末でも同じ URL と合言葉を入れれば共有できます。

### 動作

- 登録・編集・削除するたびにスプレッドシートへ送り、最新の一覧を取り込みます。アプリを開いたときや、ほかのアプリから戻ってきたときにも同期します
- 通信できないときは端末内に保存しておき、次の同期で送ります
- スプレッドシートの「本棚」シートを直接編集しても構いません。行を手で書き足す場合は ISBN だけでも OK です（ID と追加日時は自動で補われます）。「状態」列は `未読` / `読書中` / `読了` / `貸出中` のいずれか
- 同じ ISBN の本が別の端末で先に登録されていた場合は、スプレッドシート側の内容が優先されます

### 注意

- ウェブアプリの URL と合言葉を知っている人は一覧を読み書きできます。人に教えないでください
- `gas/Code.gs` を更新したときは、Apps Script で **デプロイ → デプロイを管理 → 編集（✏）→ バージョン：新バージョン** で再デプロイしてください（URL は変わりません）

## 構成

ビルド不要の素の HTML / CSS / JavaScript です。

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `lib/zxing-browser.min.js` | バーコード読み取り（[@zxing/browser](https://github.com/zxing-js/browser) 0.2.1, MIT）。ネイティブの `BarcodeDetector` がないブラウザ（iPhone など）で使用 |
| `sw.js` / `manifest.webmanifest` / `icon.svg` | ホーム画面追加・オフライン表示用 |
| `gas/Code.gs` | スプレッドシート連携用の Google Apps Script（スプレッドシート側に貼り付けて使う） |
